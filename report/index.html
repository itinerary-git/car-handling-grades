무스 테스트 등급표

휠베이스 6단계 × 지상고 5단계, 총 30개 등급마다 KM77 무스 테스트(회피 기동)를 가장 빠른 진입 속도로 통과한 차를 1위로 뽑았어요. 78km/h 이상을 기록한 차만 비교했어요. 칸 색이 진할수록 속도가 높아요. 칸을 누르면 해당 등급의 상위 차량과 제원이 보여요.

어떻게 뽑았나

  • 순위 기준은 KM77이 측정한 무스 테스트 통과 속도(km/h)예요. 콘을 하나도 쓰러뜨리지 않고 통과한 가장 높은 진입 속도로, 높을수록 좋아요.
  • 등급 경계는 아래 칸을 포함해요. 휠베이스 2,600mm 미만 / 2,600–2,699 / … / 3,000mm 이상, 지상고 150mm 미만 / 150–164 / 165–184 / 185–199 / 200mm 이상이에요.
  • 휠베이스는 KM77 제원표 값이에요. 지상고는 KM77에 값이 있으면 그 값을 쓰고, 없으면 제조사 공표값을 넣었어요. 표에서 추정은 검증 전 추정치, 검증은 웹 검색으로 확인한 값이에요.
  • 77km/h 이하를 기록한 차는 비교 대상에서 뺐어요. 그래서 1위가 77km/h 이하였던 등급은 비어 있어요.
  • 보라색 표시는 Consumer Reports, Quattroruote, 오토뷰가 그 등급 1위 차와 견줘 핸들링이 비슷하거나 더 낫다고 평가한 차예요. 이 사이트들은 직접 인용할 수 없어서 공개 검색 결과로 확인한 내용을 요약했어요. 표시된 차는 자기 제원 등급이 달라도 비교 대상인 1위 차의 칸에 붙였어요.
  • 호박색 점선 표시는 KM77 무스 테스트 값은 없지만, Quattroruote가 YouTube에 공개한 안정성 시험(Vairano, 젖은 노면 이중 차선 변경 · 마른 노면 선회 중 차선 변경)에서 평가가 좋아 그 등급 차량과 비슷하거나 나을 것으로 예상한 차예요. 차 자신의 제원 등급 칸에 붙였고, 칸을 누르면 근거와 확신 정도가 보여요.
  • 같은 속도면 공동 1위로 표시했어요. 제조사가 다르고 시험 조건이 다른 수치(스키드패드 g, 8자 주행 시간)로 억지로 순위를 가르지 않았어요.

읽을 때 주의할 점

  • 무스 테스트 속도는 시승한 버전과 타이어에 크게 좌우돼요. 같은 모델이라도 트림이 다르면 결과가 달라질 수 있어요.
  • KM77은 영상과 기사로 결과를 발표했어도 데이터 칸이 비어 있는 경우가 있어요. 그래서 MX-5 RF(기사상 80km/h), GR86, Civic Type R, 골프 GTI, IONIQ 6 같은 차는 이 표에 빠졌어요.
  • 지상고 추정치 178대 중 순위에 영향을 주는 경계값 차량 12대만 따로 검증했어요. 에어 서스펜션 차량(E-Class All-Terrain, Q6 e-tron 등)은 높이가 바뀌어서 등급이 달라질 수 있어요.
  • KM77 표기 지상고가 제조사 공표값과 다를 때가 있어요(예: GLA 134mm). 이때도 KM77 값을 그대로 썼어요.
  • 빈 칸은 KM77 기록 차량이 없거나, 있더라도 모두 77km/h 이하인 등급이에요.
  • Quattroruote의 한계 속도는 영상 화면에만 나와서, 영상 설명에 적힌 평가와 별점, 속도 3건만 썼어요. 두 곳에서 모두 시험한 Opel Astra(Quattroruote 젖은 노면 88km/h·4성, KM77 76km/h)를 보면 두 시험 수치는 바로 바꿔 쓸 수 없어요. 그래서 호박색 표시는 예상일 뿐 측정값이 아니에요.
  • 보라색 표시는 세 사이트를 검색해 찾은 만큼만 반영했어요. 표시가 없다고 해서 비슷한 차가 없다는 뜻은 아니에요.

7개 사이트 활용 범위

요청하신 7개 사이트 중 무스 테스트를 같은 방식으로 대량 측정해 공개하는 곳은 KM77뿐이어서, 등급 순위는 KM77 한 곳으로 매겼어요. 나머지는 접근 제한이 있어 공개 검색 결과로 일부 차량만 교차 확인했어요.

사이트활용내용
KM77 (스페인)순위 기준차량별 실측 페이지 1,177개를 확인해 무스 테스트 값이 있는 291대를 추렸어요. robots.txt가 막은 목록·검색 경로는 쓰지 않았어요.
Teknikens Värld (스웨덴)보도 인용이용약관이 데이터 수집을 금지해서 직접 수집하지 않았어요. 보도된 수치로 Model 3 72km/h, Model Y 75km/h를 확인했어요. KM77(83km/h)과 코스·판정이 달라 수치를 섞지 않았어요.
Car and Driver (미국)일부 확인Kia Stinger GT AWD 스키드패드 0.91g를 확인했어요. 스키드패드는 정상 선회 한계라 회피 기동과 직접 비교하지 않았어요.
MotorTrend (미국)일부 확인Model S Plaid 8자 코스 23.5초(평균 0.90g), Model Y 스키드패드 0.86g를 확인했어요. 이 사이트는 자동 수집을 막고 있어요.
Consumer Reports (미국)비교 평가 1건회피 기동 점수는 유료 회원 전용이에요. 공개 검색 결과로 Model Y가 Model 3와 핸들링이 비슷하다는 평가를 찾아 W4G1 칸에 표시했어요. Q5와 X3처럼 1위끼리 비교한 내용은 표시하지 않았어요.
Quattroruote (이탈리아)영상 참고 3대공개 YouTube 재생목록 "Prove di stabilità" 영상 74개의 제목과 설명을 확인해 호박색 후보 3대를 골랐어요. KM77 기록이 77km/h 이하인 차(Astra, 500X, i30, i4)는 KM77 값을 우선해 표시하지 않았어요. 평가 문장 비교에서는 조건에 맞는 평가를 찾지 못했어요. Model 3가 BMW 3시리즈보다 운전 재미가 낫다는 평가는 1위 차가 더 좋다는 반대 방향이었어요. 골프가 308보다 세팅이 날카롭다는 2026년 비교는 1위(2017년형 308)와 세대가 달라 뺐어요.
오토뷰 (한국)해당 없음조건에 맞는 평가를 찾지 못했어요. 검색에 나온 G70이 스팅어보다 낫다는 평가, 폴스타 2가 Model 3보다 낫다는 평가는 오토뷰가 아닌 다른 매체나 커뮤니티 글이라 뺐어요.
